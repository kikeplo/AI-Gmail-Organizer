# AI Gmail Organizer

AI-powered Windows desktop overlay for intelligent Gmail organization and productivity automation.

## Status

🚧 Early development — v0.1 desktop overlay scaffold.

## Planned capabilities

- Windows desktop overlay
- Natural-language commands
- Gmail OAuth integration
- Email search, categorization, labeling, archiving, and drafting
- AI-powered inbox organization
- Confirmation before destructive actions

## Tech stack

Python · PySide6 · Gmail API · SQLite · AI tool calling

## Run locally

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
python main.py
```

See `docs/architecture.md` for the current architecture and roadmap.
