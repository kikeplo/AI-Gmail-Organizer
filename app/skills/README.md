# Skills

Skills are reusable local capabilities composed from semantic steps. Built-in skills cover common Gmail and desktop actions; learned skills can be added locally after successful workflows.

The registry is intentionally provider-independent. The AI may discover relevant skills and combine them into a plan, while execution remains subject to the existing action-permission policy.

Examples:
- Open Gmail
- Open Promotions
- Find Unread Gmail
- Inspect Screen
- Archive Email
